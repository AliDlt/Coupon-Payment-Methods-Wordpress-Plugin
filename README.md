# محدودیت روش پرداخت کد تخفیف ووکامرس

افزونه‌ای رایگان برای تعیین روش‌های پرداخت مجاز برای هر کد تخفیف ووکامرس.

## امکانات

- نمایش روش‌های پرداخت ثبت‌شده در ووکامرس در صفحه ویرایش هر کوپن
- محدودیت مستقل برای هر کوپن
- سازگار با درگاه‌هایی مثل زرین‌پال، دیجی‌پی و اسنپ‌پی، بدون وابستگی به شناسه ثابت درگاه‌ها
- کوپن‌های موجود تا وقتی محدودیت را فعال نکرده‌اید، بدون تغییر کار می‌کنند
- با تغییر روش پرداخت در تسویه‌حساب، مبلغ تخفیف دوباره بررسی می‌شود و برای روش غیرمجاز از جمع سفارش حذف می‌شود

## نصب

پوشه افزونه را در `wp-content/plugins/` کپی و از پیشخوان فعال کنید. سپس در تب «محدودیت استفاده» هر کوپن، «محدودیت روش پرداخت» را پیکربندی کنید. متن پیام خطا از مسیر ووکامرس ← تنظیمات کد تخفیف تغییر می‌کند.

صفحه تنظیمات سراسری برای انتخاب روش‌های پرداختِ مجاز وجود ندارد؛ این انتخاب باید در خود هر کد تخفیف انجام شود. صفحه تنظیمات افزونه فقط متن پیام خطای روش پرداخت نامجاز را تعیین می‌کند.

## مخزن گیت‌هاب
