تعیین روش پرداخت مجاز برای هر کد تخفیف ووکامرس و نوشتن متن دلخواه برای پیام خطای روش پرداخت نامجاز.

پیوند گیت‌هاب تا زمان انتشار مخزن اصلی به صفحه جستجوی مخزن افزونه هدایت می‌شود و پس از انتشار باید با نشانی مخزن جایگزین شود.

== توضیحات ==

این افزونه برای هر کد تخفیف، در تب «محدودیت استفاده» گزینه‌ای اضافه می‌کند تا مشخص کنید کد با کدام روش‌های پرداخت قابل استفاده باشد. روش‌های پرداخت از درگاه‌های ثبت‌شده در ووکامرس خوانده می‌شوند؛ بنابراین فقط نام فارسی/نمایشی درگاه‌ها مانند زرین‌پال، دیجی‌پی و اسنپ‌پی نشان داده می‌شود.

صفحه تنظیمات افزونه زیر منوی ووکامرس فقط برای تعیین متن خطای پرداخت نامجاز است؛ تنظیم درگاه‌های مجاز صفحه سراسری ندارد و باید در خود هر کد تخفیف انجام شود. متن پیش‌فرض پیام «این کد تخفیف فقط برای پرداخت نقدی معتبر می‌باشد.» است و از صفحه تنظیمات قابل تغییر است.

اگر محدودیت برای یک کوپن فعال نباشد، رفتار قبلی آن کوپن حفظ می‌شود. بعد از تغییر روش پرداخت در تسویه‌حساب، ووکامرس دوباره جمع سفارش و کوپن‌های اعمال‌شده را محاسبه می‌کند؛ اگر روش جدید برای کوپن مجاز نباشد، تخفیف از جمع سفارش حذف و پیام تنظیم‌شده نمایش داده می‌شود. با انتخاب دوباره روش مجاز، تخفیف در محاسبه بعدی برمی‌گردد.

== نصب ==

1. پوشه `coupon-payment-methods` را در مسیر `/wp-content/plugins/` قرار دهید یا ZIP افزونه را از بخش افزونه‌ها بارگذاری کنید.
2. افزونه را فعال کنید. ووکامرس باید نصب و فعال باشد.
3. از مسیر ووکامرس ← کدهای تخفیف یک کوپن را ویرایش کنید.
4. در تب «محدودیت استفاده»، بخش «محدودیت روش پرداخت» را فعال و روش‌های مجاز را انتخاب کنید.
5. برای تغییر پیام خطا، از مسیر ووکامرس ← تنظیمات کد تخفیف اقدام کنید.

== پرسش‌های متداول ==

= آیا افزونه به زرین‌پال، دیجی‌پی یا اسنپ‌پی وابسته است؟ =

خیر. افزونه شناسه و عنوان درگاه‌ها را از ووکامرس می‌گیرد و با هر درگاهی که افزونه‌اش به‌درستی در ووکامرس ثبت شده باشد کار می‌کند.

= اگر محدودیت فعال باشد و هیچ درگاهی انتخاب نشده باشد چه می‌شود؟ =

کوپن با هیچ روش پرداختی معتبر نخواهد بود.

= آیا کوپن‌های قدیمی محدود می‌شوند؟ =

خیر. محدودیت هر کوپن به‌صورت پیش‌فرض خاموش است.

= تنظیمات درگاه‌ها کجاست؟ =

در صفحه ویرایش هر کوپن و در تب «محدودیت استفاده». صفحه تنظیمات ووکامرس فقط متن پیام خطای روش پرداخت نامجاز را کنترل می‌کند.
